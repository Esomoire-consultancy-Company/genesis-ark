# Platform Glossary

Key terminology used throughout Genesis Ark and the Virtual Silk Road ecosystem.

| Term | Definition |
|---|---|
| **Genesis Ark** | Root orchestration platform and control plane for the Virtual Silk Road. |
| **Virtual Silk Road** | The overarching infrastructure network that Genesis Ark orchestrates. |
| **RiverOS** | The telemetry and observability sub-system; provides event streaming and metrics. |
| **EmpireOS** | The licensing and governance sub-system; enforces policies and access control. |
| **SynergizeOS** | The operational planning sub-system; manages workflows across the platform. |
| **SILK** | Commodity-backed token used as the primary value-transfer mechanism on the platform. |
| **Observable Commerce** | Phygitech asset registry that tracks physical-digital assets. |
| **Phygitech** | Physical-digital asset — a real-world asset with a corresponding digital representation. |
| **Control Plane** | The management layer that orchestrates, configures, and monitors the data plane. |
| **CloudEvents** | An open specification for describing event data; used for all telemetry events. |
| **ADR** | Architecture Decision Record — a document capturing a significant architectural decision. |
| **OPA** | Open Policy Agent — the policy engine used by EmpireOS for runtime governance. |
