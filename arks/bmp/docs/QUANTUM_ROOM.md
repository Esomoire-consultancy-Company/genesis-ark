# Quantum Room — scheduled live presence

Quantum Room binds a time-bounded `session_id` to an admitted host, participating DigitalMe principals, eligible room/stage, approved media channels, recording consent and River event receipts.

**Proposed A-1204 demonstration:** 10:00 IST Dubai prospect; 14:30 IST London prospect. These are planning examples only, **not verified bookings**. Host assignment is proposed, pending DigitalMe role binding and availability.

Client surfaces: phone, room-edge terminal, approved Warden eyewear. Session roles: guest, buyer, host, field operator, reviewer. Stage variants: TODAY / PLANNED / FINISHED / CONFIGURED / DELIVERED. A stage toggle does not establish physical truth.

Session operations: CREATE → WARDEN_ADMIT → START → RENDER → CAPTURE_OPT_IN → FINISH → EVIDENCE_PENDING → CLOSE. External scheduling/video providers need a registered capability, usage entitlement and a revocation path. Do not automatically record private video/audio.
