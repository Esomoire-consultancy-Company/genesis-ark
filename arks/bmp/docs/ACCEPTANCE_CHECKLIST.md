# Item acceptance

A work item is **not accepted** without identity, permission, context, action, evidence, Warden review (or documented nonapplicability), BNR review (or documented nonapplicability), outcome, and record closure.

| Gate | Record |
|---|---|
| Identity | Principal and accountable entity, validity window |
| Permission | Scope, consent, license, policy decision |
| Context | Estate/Place/Location and physical asset mapping |
| Action | Requested operation, parameters, provider |
| Evidence | Provenance, source, digest, verified timestamp |
| Warden review | Allow/deny/conditional and revocation |
| BNR review | Assurance check or stated N/A |
| Outcome | Result, defects, financial and support obligations |
| Closure | Record owner, retention, lifecycle state |

Unverified or simulated evidence must be explicitly marked as such. `Pilot Ready` is not `Live`; `Live` is not `Evidence Closed`.
