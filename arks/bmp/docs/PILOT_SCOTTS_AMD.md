# 14-day pilot — SCOTTS/AMD A-1204

**Pilot start is a planning baseline, not actual physical progress.** Gate transitions require evidence, no date alone changes state.

| Days | Board status | Required result | Stop / go evidence |
|---|---|---|---|
| 0–2 | Intake → Spec Ready | Secure consent to source site material; validate location/identity; map six anchors | Property authority, inventory and dated source evidence |
| 3–5 | Build Ready → In Progress | Configure TODAY / PLANNED / FINISHED / CONFIGURED / DELIVERED and commercial rail | BIM/visual licenses, provider resource plan |
| 6–8 | Warden / BNR Review | Verify specifications, permissions, operator attestations and disclosures | Review receipts and claim register |
| 9–11 | Pilot Ready | Approved host; simulated Dubai/London sessions; wood-option resolver | Script, recording consent, Warden grant |
| 12–14 | Live/Operating → Evidence Closed | Only when accepted: controlled showing, offer workflow, closure | Source-backed approvals, signed instrument when relevant |

Owner, title, statutory approvals, site facts, legal conveyance, delivery warranties, real buyer leads and session bookings are all **unverified**. Only the demo fixture and documented workflow can be marked complete at this stage.
