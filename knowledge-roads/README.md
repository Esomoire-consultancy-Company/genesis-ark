# VSR-FOR-001 — Knowledge Roads (R0.3 review proposal)

A public reference-discovery slice for the existing Genesis / VSR engineering repository. A framework can act as a road, navigator, engine *candidate*, bridge, or checkpoint. These are descriptive roles, never authority grants.

## Responsibilities and hard boundaries

- **Genesis:** authoritative framework identities and versioned qualification; `FOR-xxxx` labels remain unregistered proposals.
- **DigitalMe:** independently verified human originator, consent and mandate for any protected route.
- **Warden:** scoped admission to `navigate.readonly` via an actual trusted verifier. The current Engineering Station Alpha Warden only supports registered container restart; never reuse that permission for navigation or engines.
- **VSR:** public Knowledge Station reference discovery without private principal or provider data.
- **Synnergyze:** qualified orchestration only after a separately approved action capability.
- **RiverOS:** true signed evidence for protected transitions, never synthetic demo receipts.

`navigation.py` exposes `browse.public` and fails closed for `navigate.readonly`. It does not connect to an identity service, engine, provider, physical device, RiverOS, or live Genesis Cloud. Untrusted client permit flags have no effect.

## Integration checkpoints

1. Independently review original attribution, source and technical applicability for all framework objects.
2. Assign real versioned Genesis IDs through an authorized registrar; separately record proposed-to-actual mappings.
3. Implement verified DigitalMe/estate/role claims and a server-side Warden `navigate.readonly` policy, including purpose, expiry, route hash and scoped consent.
4. Add the public Knowledge Roads view to the VSR interface; keep private datasets server-side.
5. Validate RiverOS receipts and staging assurance before enabling any execution adapter.

Verify: `python3 -m unittest discover -s knowledge-roads -p 'test_*.py' -v`

**State:** proposed code in review; not deployed, registered or granted authority.
